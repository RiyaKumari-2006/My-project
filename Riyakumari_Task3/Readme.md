# CSS Selectors Practice

## Overview

This is a basic HTML and CSS practice project created to learn different HTML elements and CSS selectors. The page demonstrates headings, paragraphs, lists, text formatting, and the use of inline as well as external CSS.

## Features

* HTML document structure
* External CSS using `style.css`
* Class and ID selectors
* Headings (`h1`, `h2`, `h3`)
* Paragraphs with different text colors
* Text formatting using:

  * `<span>`
  * `<mark>`
  * `<u>`
* Unordered List (`ul`)
* Ordered List (`ol`)

## Technologies Used

* HTML5
* CSS3

## Project Structure

```
project-folder/
│── index.html
│── style.css
│── README.md
```

## Learning Objectives

* Understand the basic structure of an HTML document.
* Learn how to link an external CSS file.
* Practice using class and ID selectors.
* Apply different text colors and font sizes.
* Use inline elements like `<span>`, `<mark>`, and `<u>`.
* Create ordered and unordered lists.
